# WALI 0.1.1

Discover and wallpaper detail artwork now stays within the window as it is
resized. Titles, carousel controls, favorites, and Add to Library remain visible
at compact and wide window sizes. Returning from a wallpaper also keeps the
featured artwork aligned with its title.

The production catalog includes live wallpapers and JPEG/PNG still wallpapers.
Download verified catalog media into your library, preview it, and apply it per
display. Existing libraries and display assignments are preserved.

This direct-download edition uses email codes for sign-in and requires macOS 15
or later. Native Sign in with Apple belongs to the separate Store edition; this
GitHub release is not an App Store submission.

Initial catalog media is supplied through the owner’s paid redistribution
agreement with Wallsflow and the publisher. Listings retain source and supplied
creator credits.
