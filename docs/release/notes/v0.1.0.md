# WALI 0.1.0

WALI brings live and still wallpapers to macOS with a native library and an
online catalog. This direct-download edition uses email codes for sign-in.

- Browse the catalog by category, search, newest and popularity. Discover can
  follow your selected interests, saves and completed installations.
- Save catalog items to your account and download verified wallpapers into
  your local library. Download totals update after successful installation.
- Publish licensed live wallpapers from Creator Studio after accepting the
  current terms and supplying rights and credits. Processing and publication
  continue with the app closed; failed processing can retry the retained source.
- Import supported still images and videos locally, apply wallpapers per
  display, and preserve your library and assignments across restarts.
- The saved library follows the native grid design, and playback status now
  explains Low Power Mode and thermal pauses accurately.

Requires macOS15 or later. The universal application supports Apple silicon
and Intel Macs. Use the signed disk image to drag WALI into Applications, or
extract the ZIP. Both packages include the same application.

Public Creator currently accepts supported MP4 and MOV live wallpapers.
Still-image imports are available locally; hosted still-image publication is
not enabled in this release. Native Sign in with Apple belongs to the separate
Store edition. This GitHub release is not an App Store submission.

Initial catalog media is provided under the owner's paid redistribution
agreement with Wallsflow and the publisher. Individual listings retain their
source and supplied creator credits; no original creator is invented.
